CACHE CONTENTION
The cache line is juggled between cores, and each transfer costs 10 to 100 ns. 
Only one core can own the line at a time, 
so under contention the "parallel" CASes run one after another, plus the transfer costs

Even with CAS, if head and tail and production_done all are declared next to each other
the cache would have to be passed between P and C

to avoid this, we can group variables such that var P writes are sitting on cache line together (head, production_done)
and C on another cache line 

we can use std::hardware_destructive_interference_size
to make sure head and tail start on differnet cache lines
